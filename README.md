# Government Schemes Aggregator

## Overview

Government Schemes Aggregator is a full-stack web application designed to help citizens easily discover government schemes from a single platform. Instead of visiting multiple government websites, users can search and filter schemes by category, state, and government authority.

The project aims to improve accessibility and awareness of public welfare programs by organizing scheme information in a user-friendly interface.

---

## Features

* Search government schemes
* Filter by category

  * Education
  * Healthcare
  * Employment
  * Agriculture
  * Social Welfare
* Central Government and State Government classification
* Responsive user interface
* REST API-based architecture
* Easy-to-extend project structure

## Installation

### Clone Repository

```bash
git clone https://github.com/your-username/government-schemes-app.git
```

### Navigate to Project

```bash
cd government-schemes-app
```

---

## Backend Setup

```bash
cd backend
npm install
npm start
```

Server will start on:

```text
http://localhost:5000
```

---

## Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend will start on:

```text
http://localhost:5173
```

## Problem Statement

Government schemes are often scattered across multiple websites, making it difficult for citizens to find relevant information. This project centralizes scheme information and provides a simple search and filtering experience.
